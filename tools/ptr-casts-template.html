Melee Pointer Cast Index

Every place the tree reinterprets a pointer or walks one by a literal byte count — the sites where a struct field has not yet replaced a raw offset. Grouped by what the code is actually doing, not by where the parentheses land.

What the sites do

Warm categories move a pointer by a constant; cool categories only change its type. Click to filter.

Literal offsets in use

Hex constants added to or subtracted from a pointer. Each one is a struct field waiting to be named.

Where they live

Method. Comments and string literals are blanked, then each site is classified once by its outermost form — a *(f32*)((u8*)p + 0xE0) counts as one cast+offset, not three casts. Nested plain casts inside a deref or index form are folded into the parent.

Freshness. This page is regenerated by tools/ptr_casts.py on every push to the default branch, so the counts track the tree rather than a snapshot.

Precision. ptr-to-int and raw-offset are heuristic: an identifier counts as a pointer when it is declared with a * in the same function body or at file scope, and narrow casts (u8, s16) are excluded since a pointer is never truncated to one. Expect a few false positives there; the other six categories are syntactic and exact.
